# Healthy Fitness (frontend)

React + TypeScript + Vite. Данные пока в localStorage (мок-слой `src/store.ts`) —
при подключении бэкенда заменить тела функций на fetch-запросы, сигнатуры оставить.

## Запуск

    npm install
    npm run dev      # разработка
    npm run build    # проверка типов + сборка

## Что внутри

- **Темы:** светлая/тёмная, переключатель в шапке, выбор запоминается.
- **Роли:** пациент, физиотерапевт, админ. У каждой роли свой набор разделов,
  недоступные разделы защищены (сброс на дефолтный раздел роли).
- **Пациент:** тренировки, упражнения, «Золотая эра», раздел «Здоровье»
  (ИМТ, калории и КБЖУ, дневник веса с графиком), чат с физиотерапевтом, анкета.
- **Физиотерапевт** (`therapist@demo.ru` / `demo1234`): кабинет «Мои пациенты» —
  просмотр анкет, назначение тренировок с комментарием, внутренние комментарии,
  чат с пациентами.
- **Админ** (`admin@demo.ru` / `demo1234`): «База упражнений» — добавление своих
  упражнений с собственным видео (ссылка или файл) и описанием; пополняет общий каталог.
- **Легенды «Золотой эры»:** по клику на карточку раскрывается программа тренировок
  легенды с предупреждением, что объёмы рассчитаны на профессиональных атлетов.

Демо-аккаунты физиотерапевта и админа создаются автоматически при первом входе/регистрации.
